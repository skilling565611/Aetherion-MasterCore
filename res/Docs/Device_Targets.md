# Device Targets

## Control Prime

Control Prime is the main PC and development/build machine.

- full master system
- heavier local processing allowed
- local AI tools stored here
- GitHub/Codex integration
- full/dev mode

## Arctic Prime

Arctic Prime is the portable control hub.

- lightweight runtime
- offline-first
- low RAM/CPU usage
- fast startup
- tablet/foldable mode support planned
- floating keyboard support planned
- local tools only unless user enables more

Do not force heavy systems onto Arctic Prime.
