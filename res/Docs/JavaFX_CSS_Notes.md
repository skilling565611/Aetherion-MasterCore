# JavaFX CSS Notes

Main theme file:

`src/main/resources/com/dev/aetherion/styles/Main.css`

Rules:

- keep dark controls readable
- avoid default white JavaFX text boxes, list views, and text areas
- use cyan, green, amber, and red accents sparingly
- keep panels at 8px radius unless a future design system changes this
- prefer stable shell layout changes only after explicit approval

Key colors:

- background: `#0b1017`, `#101418`
- panel: `#10263d`, `#08111d`
- cyan: `#00d9ff`, `#00efd8`
- green: `#00ff95`
- amber: `#ff9f1c`
- warning: `#ff4b5c`
- readable text: `#d7f8ff`
- muted text: `#9fc2d6`
