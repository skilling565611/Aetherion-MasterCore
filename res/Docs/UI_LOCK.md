# Aetherion UI Lock

The V1.0 shell is protected once created.

Protected areas:

- top bar
- left sidebar
- center workspace container
- right rail
- footer/status area
- dark cyber/offline-AI visual identity

Allowed changes:

- section content inside the center workspace
- controller wiring
- backend logic
- bug fixes
- readability fixes
- scroll and responsive fixes

Not allowed without explicit approval:

- moving the sidebar
- moving the top bar
- moving the right rail
- replacing the whole theme
- redesigning the dashboard identity
