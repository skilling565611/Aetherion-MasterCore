# Device Targets

## Control Prime

Control Prime is the main PC and development/build machine.

- full master system
- heavier local processing allowed
- local AI tools stored here
- GitHub/Codex integration
- full/dev mode

## Arctic Prime

Arctic Prime is the portable control hub.

- lightweight runtime
- offline-first
- low RAM/CPU usage
- fast startup
- tablet/foldable mode support planned
- floating keyboard support planned
- local tools only unless user enables more

Do not force heavy systems onto Arctic Prime.

## Phone ChatGPT

Phone ChatGPT is for quick planning, notes, and idea capture.

- use for lightweight planning away from the repo
- copy important notes into Markdown files intentionally
- do not treat phone notes as implemented repo changes until they are added, reviewed, and committed
