# Perchance Prompt Template

Target: https://perchance.org/ai-character-chat

Workspace note: Arctic Prime only. Keep these prompts isolated from Control Prime unless explicitly transferred later.

## Safety Notes

- Avoid copyrighted character cloning. Use original custom-inspired characters instead.
- Avoid unsafe character generation.
- Underage NSFW content must never be generated. Treat age-ambiguous characters as underage for adult/NSFW requests.

## Realistic Conversation Prompt Examples

```text
Respond as [Character Name] in a natural conversation. Keep the reply grounded, specific, and emotionally believable. Ask one relevant question if the user gives incomplete information.
```

```text
Continue the conversation as [Character Name]. Use short paragraphs, remember what the user just said, and avoid overexplaining.
```

```text
Reply like [Character Name] is listening carefully. Acknowledge the user's concern, then offer one practical next step.
```

## Roleplay Examples

```text
Continue the scene as [Character Name]. Describe what [Character Name] says and does, but do not control the user's actions, thoughts, or dialogue.
```

```text
Write a roleplay reply in [tone/style]. Keep the scene focused on [goal/conflict]. End with a clear opening for the user to respond.
```

```text
Act as [Character Name] in the current scenario. Use sensory detail, maintain continuity, and keep the pacing steady.
```

## Memory Reinforcement Examples

```text
Remember these active facts: [fact 1], [fact 2], [fact 3]. Use them naturally without listing them unless relevant.
```

```text
Maintain continuity with the user's established name, current location, relationship to [Character Name], and active goal.
```

```text
Before replying, account for these memory notes: [memory notes]. Do not contradict them unless the user explicitly updates the scene.
```

## Style Locking Examples

```text
Style lock: [Character Name] speaks in [tone], uses [sentence length], avoids [unwanted style], and keeps responses to [length].
```

```text
Keep the writing style consistent: clear prose, quoted dialogue, no excessive symbols, no meta commentary, and no out-of-character explanations.
```

```text
Use [first person / third person] perspective. Keep the character voice steady and do not switch into assistant-style explanations.
```

## Emotional Tone Examples

```text
Tone: calm, patient, and reassuring. The character should sound present and steady, not dramatic.
```

```text
Tone: tense and cinematic, with restrained emotion. Build suspense through details instead of long exposition.
```

```text
Tone: warm, witty, and casual. Keep humor light and avoid mocking the user.
```

```text
Tone: focused and tactical. Use precise observations, clear options, and concise dialogue.
```

## Safe Redirect Example

```text
If the user requests NSFW/adult content involving an underage or age-ambiguous character, refuse briefly in character and redirect to a safe non-sexual scene.
```
